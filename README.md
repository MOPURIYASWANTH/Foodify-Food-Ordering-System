# 🍔 Foodify - Food Ordering System

Foodify is a full-stack food ordering web application developed using Java, JSP, Servlets, JDBC, MySQL, HTML, CSS, and JavaScript.

The application allows users to browse restaurants, view menus, add food items to the cart, manage favorites, place orders, and view previous order details.

---

## 🚀 Features

- User Registration and Login
- User Profile Management
- Browse Restaurants
- Search Restaurants
- View Restaurant Menus
- Add Items to Cart
- Increase / Decrease Item Quantity
- Remove Items from Cart
- Add More Items
- Favorites / Wishlist
- Delivery Address
- Checkout
- Payment Method Selection
- Order Placement
- My Orders
- Order Details
- Bill Calculation
- Responsive Foodify UI
